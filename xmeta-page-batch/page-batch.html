Tạo Page theo lô

Nhập danh sách, kiểm tra từng Page rồi gửi tuần tự qua Meta Graph API. Các chức năng XMETA hiện có vẫn mở bằng biểu tượng tiện ích.

Điều kiện Meta: API tạo Page chỉ dùng được với tài khoản thử nghiệm hoặc ứng dụng được Meta cho phép, cùng User access token có quyền pages_manage_metadata và pages_show_list. Công cụ dừng khi Meta từ chối quyền hoặc cảnh báo lạm dụng. Không có tốc độ nào bảo đảm tránh giới hạn hay bộ lọc spam.

1. Danh sách Page

CSV cần cột name, category_enum; cột about có thể bỏ trống. category_enum là giá trị api_enum của Meta Page Category.

2. Kết nối Meta

Token không được lưu vào Chrome Storage hoặc tệp kết quả. Trang này xóa ô token sau khi dừng hoặc hoàn tất.

Mỗi yêu cầu gửi riêng lẻ. Khi Meta báo giới hạn, công cụ đọc Retry-After và mức sử dụng API để chờ lâu hơn. Nếu mất kết nối trong lúc tạo Page, kết quả được đánh dấu “chưa rõ” để bạn kiểm tra trước khi chạy lại.
